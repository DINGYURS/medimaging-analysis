# 品牌 Logo

采用已确认的 A 方案：切片 M。以层叠的蓝色切片构成 MedImaging 首字母 M，保留斜向留白。

- 页面图形源文件：frontend/src/assets/brand-mark.svg。
- 统一组件：frontend/src/components/BrandMark.vue；公共页眉、登录页和注册页均引用此组件。
- 独立图标：frontend/public/brand/mark.svg。
- 横向中英文组合：frontend/public/brand/logo.svg。
- 浏览器标签图标：frontend/public/favicon.svg；图形与页面 Logo 相同，采用正方形画布。
- 主色 #2563EB，深色切片 #1648B5，文字色 #162C46。
- 页面名称使用真实文字，深浅主题跟随系统配色；图形透明背景，无描边、阴影或圆角底板。
- 修改图形时同步更新上述 SVG，保持各场景一致。
